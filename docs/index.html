桌面卡片，抬眼即见

HarmonyOS 服务卡片与 Android 原生 AppWidget 各两枚：2×2 速览与 2×4 列表，把最紧的那个窗口钉在桌面与锁屏。

  • hero 泳道：同服务商多个窗口里最紧的一条做大号数字，如 Claude 周窗 96% 比会话窗更紧时直接显示 96%。
  • 轮播与挑选：鸿蒙卡片 Swiper 一页一家；显示哪几家在设置页点选，顺序即卡片顺序。
  • 余额回退：无配额窗口但快照成功的服务商显示余额数字，不再整条消失。
  • 深浅色自适应：卡片配色跟随系统；点击任意位置直达应用。刷新成功即时推送，另有 30 分钟定时兜底。

登录一次，到处是你的账号

凭证两条线并存：API Key 直连，或应用内网页登录自动捕获会话；同一服务商可挂多套账号。

应用内网页登录

Codex 走 PKCE 授权，refresh token 静默续期；Claude 自动捕获 sessionKey；DeepSeek 直接抓取平台会话。401 时无感重试，不用反复登录。

多账号管理

点账号 chip 立即切换并刷新，长按重命名或删除；同凭证自动去重，删除后自动转移到剩余账号。

凭证只存在你的手机里

CodexBar 不内置任何统计或账号系统：没有后端，没有埋点，刷新即直连服务商官方接口。

不收集、不上传任何数据 凭证仅存本机（Preferences） 刷新直连服务商接口
